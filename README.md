# 🌐 Apocalypse Hub (아포칼립스 허브)

> **Gemma 4 E4B 멀티모달 로컬 LLM 허브 (Termux / Android S24 Ultra 최적화)**
> 
> 기기를 초기화하거나 다른 안드로이드 단말기로 옮길 때도 명령어 한 줄로 5분 만에 모든 환경을 복구할 수 있는 원클릭 셋업 환경입니다.

---

## 🚀 빠른 시작 (원클릭 설치)

안드로이드 단말기의 **Termux** 앱에서 아래 명령어를 복사하여 붙여넣으면 설치부터 최적화 빌드, 모델 다운로드까지 한 번에 완료됩니다:

```bash
pkg update -y && pkg install -y git && git clone https://github.com/ishuca12625-lab/apo-hub.git && cd apo-hub && chmod +x setup.sh && ./setup.sh
```

## ⚙️ 주요 특징

### 1. 중단 후 재실행 시 스마트 스킵 (이어받기 지원)
- **패키지 검사 스킵**: 필수 패키지(`clang`, `cmake`, `glslc` 등)와 헤더가 이미 설치되어 있다면 `pkg update`의 지루한 지연 없이 0.1초 만에 건너뜁니다. (패키지 강제 업데이트: `./setup.sh --update-pkgs`)
- **Vulkan 빌드 보존**: 이미 빌드된 `llama-server`가 존재하면 2단계를 건너뜁니다. (강제 재빌드: `./setup.sh --rebuild`)
- **대용량 모델 이어받기**: 모델 다운로드 중 끊기더라도 `curl -C -`로 받던 지점부터 즉시 이어받습니다.

### 2. 안전한 접속 모드 (보안 강화)
기본적으로 공공장소/외부망 보안을 위해 **로컬 전용(`127.0.0.1`)**으로 구동되며, 필요할 때만 인자를 주어 동일 Wi-Fi에 공유할 수 있습니다:

- **안전 로컬 모드 (기본값)**:
  ```bash
  ~/run_hub.sh
  ```
  스마트폰 브라우저에서 `http://127.0.0.1:8080` 접속 (외부 노출 완전 차단)

- **LAN 공유 모드 (PC / 태블릿과 공유 시)**:
  ```bash
  ~/run_hub.sh --lan
  ```
  동일 Wi-Fi 내 다른 기기에서 `http://<스마트폰-IP>:8080`으로 접속 가능 (구동 시 스크립트가 기기 IP 자동 안내)

## 📱 실전 활용 가이드 (완전 오프라인 AI 단말기화)

가장 가볍고 안정적인 방식은 `llama.cpp` 내장 경량 웹 서버(`llama-server`)를 백그라운드로 띄우고, **삼성 인터넷/크롬 브라우저 + 갤럭시 온디바이스 기능(카메라/음성)**을 결합하는 것입니다. 추가 메모리 소모가 수십 MB 수준에 불과하여 Gemma 4 E4B를 쾌적하게 구동할 수 있습니다.

### 1. 백그라운드 서버 구동
Termux에서 서버를 띄운 후 홈 화면으로 나가거나 다른 앱을 켜도 꺼지지 않습니다 (`termux-wake-lock` 적용):
```bash
~/run_hub.sh
```
로그에 `HTTP server listening at http://127.0.0.1:8080`이 표시되면 정상 가동 상태입니다.

---

### 2. 홈 화면 앱(PWA) 등록 (단독 앱처럼 사용)
브라우저 주소창 없이 전체 화면 단독 앱처럼 사용하는 방법입니다:

1. **삼성 인터넷** 또는 **크롬**을 엽니다.
2. 주소창에 `http://127.0.0.1:8080`을 입력하고 이동합니다.
3. **홈 화면에 추가**:
   - **삼성 인터넷**: 우측 하단 `더보기(≡)` → `현재 페이지 추가` → `홈 화면`
   - **크롬**: 우측 상단 `더보기(⋮)` → `홈 화면에 추가`
4. 이제 바탕화면에 생성된 아이콘을 누르면 주소창 없는 깔끔한 전체 화면 AI 챗봇 앱으로 즉시 실행됩니다.

---

### 3. 카메라 직결 & 사진 분석 (Vision 멀티모달)
`--mmproj` 프로젝터가 연동되어 있어 시각 인식이 완벽하게 작동합니다:
- 대화 입력창 옆 **클립(첨부) 아이콘**을 터치합니다.
- 안드로이드 시스템 메뉴에서 **'카메라'**를 선택해 고장 난 기계 부품, 약초, 지도, 외국어 문서 등을 즉석에서 촬영하거나, **'갤러리'**에서 사진을 첨부해 프롬프트와 함께 질문합니다.

---

### 4. 완전 오프라인 초고속 음성 대화 (Voice)
> [!TIP]
> **왜 Whisper 모델을 추가로 띄우지 않나요?**  
> 모바일 환경에서 무거운 STT 모델(Whisper 등)을 별도로 돌리면 NPU/GPU 자원 충돌과 메모리 부족으로 인해 텍스트 생성 속도가 심각하게 저하됩니다. 대신 갤럭시 S24 Ultra 자체 내장 온디바이스 NPU 음성 엔진을 사용하면 자원 소모 0으로 번개 같은 음성 대화가 가능합니다.

#### 오프라인 음성 언어팩 설정 (최초 1회)
1. 스마트폰 **설정** → **일반** → **삼성 키보드 설정** → **음성 입력**으로 이동합니다.
2. 음성 입력 서비스를 **'삼성 음성 입력'**으로 지정합니다.
3. **'기기 내 음성 인식 활성화'**를 켜고 필요한 언어팩(한국어, 영어 등)을 다운로드합니다.

#### 실제 대화 시
- 브라우저 대화창을 터치해 삼성 키보드가 올라오면, 스페이스바 옆이나 상단 툴바의 **마이크 아이콘**을 누르고 말합니다.
- **인터넷이 완전히 차단된 비행기 탑승 모드**에서도 온디바이스 NPU가 실시간으로 음성을 텍스트로 즉각 변환하여 프롬프트 창에 채워줍니다.

## 💡 성능 최적화 옵션 (S24 Ultra / Adreno 750)
- **Vulkan 가속**: Adreno 750 GPU를 100% 활용하는 하드웨어 가속 (`-ngl 99`)
- **최적 스레드**: 빅/미들 코어 집중 할당 (`-t 6`)
- **컨텍스트 길이**: 8,192 토큰 (`-c 8192`)
- **Gemma 4 Thinking 모드**: 사고(Thinking) 엔진 활성화 (`--chat-template-kwargs '{"enable_thinking":true}'`)
- **절전 방지**: 백그라운드 절전 모드로 인한 프로세스 킬 방지 (`termux-wake-lock`)
